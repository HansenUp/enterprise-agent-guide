# 英文术语与命名约定

## 术语展示规则

概念名称使用英文在前，中文解释放在括号内；缩写首次出现时补充英文全称。正文仍用中文解释，避免每次重复全称影响阅读。多个概念用 / 分隔，括号中的中文按顺序对应。

ReAct（Reasoning and Acting，推理与行动）是 Agent 执行模式；React 是前端 UI 库，两者大小写与含义不同。Function Calling（函数调用）是结构化调用机制，Tool Use（工具使用）是使用工具完成任务的总体能力，Tool Calling（工具调用）是常见相关称呼。

产品名、项目名和没有稳定全称的专有名称保留原名，不编造缩写展开。文件名、API 路径、Schema 字段、源文档标题和官方来源名称保持原样。旧中文概念名继续作为搜索别名保留。
